
# React Routing Task

## Overview
This project demonstrates React Router implementation for building single-page applications with multiple routes and navigation.

## Features
- Client-side routing with React Router
- Multiple page components
- Navigation between routes
- Dynamic route parameters (optional)

## Installation
```bash
npm install
npm install react-router-dom
```

## Usage
```bash
npm start
```

## Project Structure
```
src/
├── components/
├── pages/
├── App.js
└── index.js
```

## Routes
- `/` - Home page
- `/about` - About page
- `/contact` - Contact page

## Technologies Used
- React
- React Router DOM
- CSS/Tailwind (optional)
